# advance-calculator

A simple and modern calculator built with HTML, CSS, and JavaScript.

✨ Features

Addition

Subtraction

Multiplication

Division

Decimal numbers

Delete last character

Clear calculation

Error handling

Responsive design

Modern dark UI

🚀 Getting Started

Clone the repository:

git clone https://github.com/donyaadu/advance-calculator.git 

Open the project folder and run d.html in your browser.

No installation or additional dependencies are required.
